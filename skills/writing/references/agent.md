# Writing for agents

Write for an agent that may not share the original conversation. Make the intended interpretation, applicable guidance, and current state clear enough to continue without redirecting the work.

## Instructions

- Describe the desired outcome and the conditions that determine the action. Give procedural steps observable completion criteria and order them where dependencies require it. For open-ended work, provide decision criteria without prescribing every move.
- Distinguish requirements, preferences, and examples. State the desired behavior positively, reserving prohibitions for boundaries that need them. Include only guidance that changes a relevant decision or action.
- Preserve obligation strength, scope, exceptions, and authorization when revising instructions. Surface intended behavior changes explicitly.

## Context and handoffs

Separate established facts and decisions from proposals, inferences, and unresolved questions. Retain the basis and scope needed to interpret each; an example or local choice stays within its stated role.

For continuing work, identify completed results, their verification limits, remaining work, and pending decisions. Qualify time-sensitive observations so recorded state is not mistaken for a fresh check. Reference sources the receiving agent can actually access; make the authoritative information available once when earlier context is unavailable. Distinguish active guidance from superseded history.

## Organization

Distinguish ordered actions from supporting reference, keeping related definitions, rules, and exceptions together. Keep essential constraints in the current reading path; move branch-specific detail behind a reference that states when to read it.

For skills, keep the description short and specific to the actual use. When necessary guidance is missed, inspect its trigger before copying it elsewhere. Point to easily inspected environment facts and document the conventions or reasons that inspection cannot reveal.

Read from a fresh session's perspective: what would the agent treat as fact, instruction, permission, and unfinished work? Correct wording that could change any of these beyond the intended meaning.
